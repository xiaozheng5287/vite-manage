给定一个按照升序排列的整数数组 nums，和一个目标值 target。找出给定目标值在数组中的开始位置和结束位置。 如果数组中不存在目标值 target，返回 [-1, -1]。 进阶：你可以设计并实现时间复杂度为 $O(\log n)$ 的算法解决此问题吗？ 示例 1： 输入：nums = [5,7,7,8,8,10], target = 8 输出：[3,4] 示例 2： 输入：nums = [5,7,7,8,8,10], target = 6 输出：[-1,-1] 示例 3： 输入：nums = [], target = 0 输出：[-1,-1] 这段代码实现了一个在有序数组中查找目标值 target 的左右边界的算法。具体来说，它定义了三个函数：searchRight、searchLeft 和 searchRange。下面是对每个函数的详细解释： searchRight 函数 这个函数用于查找目标值 target 在有序数组 nums 中的右边界。右边界是指数组中最后一个不大于 target 的元素的索引。 实现原理： 初始化两个指针 left 和 right，分别指向数组的起始和末尾。 使用一个 while 循环，当 left 小于等于 right 时，计算中间位置 middle。 如果 nums[middle] 大于 target，则 target 在左区间，更新 right 为 middle - 1。 如果 nums[middle] 小于等于 target，则 target 在右区间，更新 left 为 middle + 1，并记录 rightBorder 为 left。 循环结束后，返回 rightBorder。 用途： 用于查找目标值 target 在数组中的右边界。 searchLeft 函数 这个函数用于查找目标值 target 在有序数组 nums 中的左边界。左边界是指数组中第一个不小于 target 的元素的索引。 实现原理： 初始化两个指针 left 和 right，分别指向数组的起始和末尾。 使用一个 while 循环，当 left 小于等于 right 时，计算中间位置 middle。 如果 nums[middle] 大于等于 target，则 target 在左区间或等于 target，更新 right 为 middle - 1，并记录 leftBorder 为 right。 如果 nums[middle] 小于 target，则 target 在右区间，更新 left 为 middle + 1。 循环结束后，返回 leftBorder。 用途： 用于查找目标值 target 在数组中的左边界。 searchRange 函数 这个函数用于查找目标值 target 在有序数组 nums 中的左右边界，并返回一个包含这两个边界的数组。 实现原理： 调用 searchLeft 函数查找 target 的左边界 leftBorder。 调用 searchRight 函数查找 target 的右边界 rightBorder。 如果 leftBorder 或 rightBorder 为 -1，说明 target 不在数组中，返回 [-1, -1]。 如果 rightBorder - leftBorder > 1，说明 target 在数组中，返回 [leftBorder + 1, rightBorder - 1]。 否则，返回 [-1, -1]。 用途： 用于查找目标值 target 在数组中的左右边界。 注意事项 数组 nums 必须是有序的，否则算法无法正确工作。 Math.ceil((left + right) / 2) 用于计算中间位置，但通常情况下，Math.floor 更为常用，因为数组索引是整数。 rightBorder 和 leftBorder 的初始值设为 -1，表示如果目标值不在数组中，返回 -1。 searchRange 函数返回的边界值需要根据实际情况进行调整，确保返回的是目标值的实际边界。 Document
